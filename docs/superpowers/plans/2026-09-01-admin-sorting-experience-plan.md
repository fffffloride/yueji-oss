# 后台排序体验实施计划

1. 服务端增加最小的单项位置移动 DTO、事务辅助函数和边界测试。
2. 为商品、商品分类、Banner、公告、代理类型、角色、字典项、部门和菜单接入位置移动接口；新建数据默认追加到末尾。
3. 会员等级取消 `sort` 语义并固定按累计实付门槛排序；分销等级取消 `sort`，固定按 `rank` 排序。
4. 增加现有数据顺序归一化 SQL，并隐藏无后端、无业务价值的租户入口。
5. 管理端增加复用的即时移动状态与原生拖拽能力，不引入新依赖。
6. 改造 11 个页面：短列表拖拽、树形同级拖拽、商品全局位置操作、两类等级自动排序。
7. 执行服务端最小单测与构建、管理端类型检查和生产构建；修复全部回归后提交两端代码。
