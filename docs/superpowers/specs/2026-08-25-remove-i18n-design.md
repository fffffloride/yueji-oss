# 管理端移除国际化设计

## 目标

管理端固定使用简体中文，完整移除语言切换入口、国际化依赖和状态逻辑，不影响主题、组件尺寸、菜单、登录及设置功能。

## 改动范围

- 删除 `LangSelect`、`src/lang`、英文/中文语言包和 `vue-i18n` 初始化。
- 将现有 `t(...)` 文案替换为当前中文文案；菜单、面包屑和页签直接显示后端提供的标题。
- 删除语言枚举、默认语言、localStorage 键、应用语言状态和切换方法。
- Element Plus 固定使用 `zh-cn` 语言包；保留其中文日期、分页等组件文案。
- 删除 `vue-i18n` 依赖及 Vite 中对应的自动导入和预构建配置。
- 设置配置复制结果不再生成 `language` 字段。

## 不改动

- 不修改后端、小程序端或业务接口。
- 不清理与 Vue/TypeScript 工具链有关但名称含 `language-core` 的间接依赖。
- 不删除二维码登录中的 `QrCodeGenerate`，它与代码生成和国际化无关。

## 验证

- 全仓扫描确认无 `vue-i18n`、`useI18n`、`LangSelect`、`src/lang` 和语言状态引用。
- 检查登录、菜单标题、工具栏和设置面板均显示中文。
- 运行 `pnpm type-check` 和 `pnpm build`。
