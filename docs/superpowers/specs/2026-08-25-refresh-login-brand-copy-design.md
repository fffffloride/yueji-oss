# 登录页品牌文案与版本号调整设计

## 目标

让登录页左侧内容符合“悦己 DLumière 医美”品牌主题，并将管理端项目版本统一调整为 `1.0.0`。

## 页面文案

- 品牌标签：`DLUMIÈRE BEAUTY`
- 主标题：`悦己而美，自在生光`
- 描述：`以专业医美服务连接每一次美好体验，让品牌、服务与成长从容发生。`
- 品牌特质：`专业医美`、`品质服务`、`精细运营`

保留登录页现有布局、图标、配色和交互，只替换左侧对应文案。

## 版本号

将管理端 `package.json` 的版本从 `4.8.4` 改为 `1.0.0`。登录页继续读取 `appConfig.version`，最终显示 `v1.0.0`，不新增独立版本常量。

## 范围边界

- 不修改登录表单文案与登录逻辑。
- 不调整页面结构、样式、Logo 或页脚。
- 不修改后端和其他项目的版本号。

## 验证

- 运行前端类型检查和生产构建。
- 确认登录页左侧显示新文案和 `v1.0.0`。
