# 预约容量修改二次确认设计

## 目标

管理员修改“每时段预约上限”时，必须在二次确认后才发送保存请求，避免误操作立即改变可预约容量。

## 交互

- 页面同时保留已生效容量和输入框当前值。
- 数值未变化时，点击“保存配置”只提示“配置未变化”，不弹窗、不请求接口。
- 数值变化时，复用 Element Plus `ElMessageBox.confirm` 显示警告弹窗。
- 文案模板为“确认将每时段预约上限从 `${savedSlotCapacity}` 人修改为 `${slotCapacity}` 人？”，按钮为“确认修改 / 取消”。
- 确认后才调用现有保存接口；保存成功后更新已生效容量并提示成功。
- 取消时不发送保存请求，保留输入框当前值供继续修改。

## 范围与验证

只修改管理端预约页保存流程，不修改服务端接口、数据库或小程序。完成后执行管理端类型检查和生产构建。
